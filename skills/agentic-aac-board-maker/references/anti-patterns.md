# AAC Generation Anti-Patterns

Use this file when reviewing generated boards or improving the skill stack. These are common ways an agent can produce a resource that looks useful but fails the student.

## 1. Noun Grid Instead Of Communication Board

Weak output:

- apple
- pear
- plum
- cake
- caterpillar

Why it fails: the student can label content but cannot comment, request, sequence, refuse, ask, or repair.

Better pattern:

- I see
- eat
- more
- finished
- first
- next
- because
- funny
- help

## 2. Quiz-Only Compliance Board

Weak output:

- correct answer
- wrong answer
- wrong answer
- wrong answer

Why it fails: the student only guesses adult-selected answers.

Better pattern:

- I think
- because
- not sure
- show me
- help
- my answer is
- different
- finished

## 3. Over-Dense Gaze Board

Weak output:

- 16 or 25 tiny choices for an untested eye-gaze user.

Why it fails: target size and scanning/gaze accuracy are sacrificed for vocabulary quantity.

Better pattern:

- 2x2, 2x3, or 3x3 page structure;
- multiple calm pages;
- large targets;
- visible dwell progress;
- stable Help/Back/Finished positions.

## 4. First-Then As Behaviour Control

Weak output:

- First work.
- Then reward.

Why it fails: the board frames the student as compliant/non-compliant and gives no agency.

Better pattern:

- First <task>.
- Then <next activity>.
- Help.
- Wait.
- Change.
- Finished.

## 5. Visual Schedule Pretending To Be Full AAC

Weak output:

- A morning routine schedule described as the student's communication system.

Why it fails: schedules mostly support receptive understanding and predictability.

Better pattern:

- Keep the schedule;
- add expressive options such as Help, Wait, More time, Change, Finished;
- state that it supplements, not replaces, AAC.

## 6. Adult Voice In Student Buttons

Weak output:

- Student will complete task.
- Student is calm.
- I am making good choices.

Why it fails: it scripts adult interpretation as the student's voice.

Better pattern:

- I need help.
- Too loud.
- Break.
- Stop.
- I don't like this.
- I need more time.

## 7. Privacy-Leaking Personalisation

Weak output:

- file names, labels, notes, or logs include diagnosis, behaviour details, family details, school IDs, or unnecessary student names.

Better pattern:

- anonymous resource IDs;
- placeholders for local editing;
- teacher-owned custom photos only when approved;
- local-only profiles when genuinely needed.

## 8. Teacher Controls In Student Mode

Weak output:

- edit, delete, export, reset, or settings buttons mixed with student choices.

Why it fails: accidental activation can break the activity or expose data.

Better pattern:

- separate teacher panel;
- locked/collapsible notes;
- confirmation for reset/export/delete;
- student board remains calm and predictable.

## 9. Symbol Decoration Without Text Fallback

Weak output:

- symbol-only buttons with no robust label or spoken text.

Why it fails: symbols can fail to load, be misread, or not match the student's symbol knowledge.

Better pattern:

- label;
- spoken text;
- symbol search term or local image;
- attribution;
- text remains meaningful without images.

## Review Question

For every generated board, ask:

```text
If all symbols failed and only text labels remained, could the student still communicate something meaningful?
```
