# Teacher Intake Template

Use only when clarification is genuinely needed.

```text
I can build this. Quick details so I make the right board:

1. Access method: touch/keyboard, eye gaze/dwell, switch scanning, or print/partner-assisted?
2. Output: single HTML file, printable board, Open AAC Studio JSON, or full resource pack?
3. Purpose: choice board, visual schedule, first-then, quiz/comprehension, sentence builder, needs/repair, curriculum/QCIA evidence, or something else?
4. Topic or goal: what lesson/routine/QCIA goal should it support?
5. Any must-have words, symbols, or things to avoid?
```

If the user does not answer, proceed with safe defaults and state assumptions.
