# Multi-AI Handoff Templates

Use these when Richard wants to move work between Claude, Codex, Gemini, custom GPTs, and Hermes.

## Claude / Cowork brief

Goal: develop educational structure, scaffolding, student language, and teacher-facing rationale.

Include:

- Student/resource context.
- Curriculum or assessment intent.
- Access needs.
- Existing files or excerpts.
- Desired output structure.
- Non-negotiables: accessible, curriculum-strong, practical, no sycophantic fluff.

## Codex implementation brief

Goal: build or modify actual files.

Include:

- Exact file path/s.
- Whether to edit original or create copy.
- Required features.
- Accessibility acceptance tests.
- Offline/single-file constraints.
- Browser/device target.
- What not to touch.

## Gemini UI/UX pass brief

Goal: improve layout, visual hierarchy, usability, and polish.

Include:

- Target users and devices.
- Screenshots or file path.
- Known pain points.
- Layout constraints: no unnecessary scrolling, large targets, central interaction area.
- Request concrete changes, not broad praise.

## Hermes final QA brief

Goal: local final check.

Check:

- File opens.
- No missing assets/CDNs if offline required.
- Keyboard works.
- Dwell/eye-gaze assumptions hold if relevant.
- High-stakes actions protected.
- Curriculum intent preserved.
- Output is practical for classroom use.
