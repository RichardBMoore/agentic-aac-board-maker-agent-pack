# Subject-Agnostic Examples

Use these as patterns, not as fixed content. Replace the target, task, and evidence with the user's curriculum source and student access profile.

## Science

Target: Explain observable changes in materials at the ICP target achievement standard level.

Evidence:

- Sort examples of physical and chemical change.
- Explain one change using oral, AAC, typed, or recorded response.
- Match vocabulary to visual examples.
- Complete a practical observation with photos and teacher notes.

Assessment pattern:

- Use the same class experiment context where possible.
- Provide an adjusted evidence sheet with images and selection responses.
- Record oral or AAC explanation.
- Judge understanding of change, not handwriting or spelling unless those are the target.

## Mathematics

Target: Solve addition and subtraction problems at the ICP target level.

Evidence:

- Use concrete materials to model a problem.
- Record an answer using numerals, symbols, AAC, selection, or speech.
- Explain the strategy using words, visuals, pointing, or AAC.
- Complete repeated problems across two contexts.

Assessment pattern:

- Keep the same class problem-solving theme.
- Reduce item count if enough evidence remains.
- Allow concrete materials where they do not invalidate the construct.
- Separate calculation accuracy from communication support.

## HASS

Target: Identify features of a place and describe how people use it.

Evidence:

- Label visual map features.
- Sort human and natural features.
- Describe one use of a place using sentence starter, AAC, oral response, or typed response.
- Use photo evidence from a local or community context.

Assessment pattern:

- Use the same inquiry question as the class where possible.
- Provide visual maps and photo cards.
- Allow spoken, selected, typed, or recorded response.
- Judge identifying and describing place features.

## English

Target: Identify ideas in a text and give a supported response.

Evidence:

- Select the main idea from choices.
- Match a detail to an idea.
- Give a reason for a preference or opinion.
- Use a sentence frame, AAC, drawing, oral response, or typed response.

Assessment pattern:

- Use the same class text when accessible, or an accessible parallel text when required.
- Reduce reading load through read-aloud, audio, larger print, or symbol support.
- Provide a visual response board if useful.
- Judge comprehension and response, not decoding, unless decoding is the target.
