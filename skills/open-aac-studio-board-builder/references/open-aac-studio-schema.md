# Open AAC Studio Schema Notes

These notes describe the practical activity JSON shape used by Richard's Open AAC Studio / Open Boardmaker prototype. The source of truth is the running app, especially `js/data.js`, `js/editor.js`, `js/player.js`, and `templates/*.json`.

> "Open AAC Studio" is Richard's private prototype, not a public app, and is unrelated to the OpenAAC organisation (github.com/open-aac) that maintains the Open Board Format. This JSON loads only in the bundled classroom-pack prototype; for files other AAC apps can import (CoughDrop, Cboard, AsTeRICS Grid, OptiKey), render the IR with `render_obf.py` instead.

## Activity Object

Core fields:

- `schemaVersion`: currently `0.1.0` in the working app.
- `app`: prefer `Open AAC Studio` for new files.
- `id`: stable anonymous ID such as `activity-year7-hero-speech`.
- `name`: teacher/editor title.
- `type`: usually `interactive`.
- `created`, `modified`: ISO timestamps if generated by code.
- `author`: optional; avoid student names.
- `settings`: player defaults.
- `accessibility`: intended access profile and design constraints.
- `pages`: ordered board pages.
- `variables`: object for score/progress/conditional actions.
- `metadata`: tags, level, curriculum, privacy.
- `licences`: attribution for symbols/media.

## Settings

Common settings:

```json
{
  "orientation": "landscape",
  "width": 1024,
  "height": 768,
  "speakLabels": true,
  "showLabels": true,
  "highlightColour": "#ffeb3b",
  "font": "Verdana",
  "fontSize": 18,
  "fontColour": "#000000",
  "backgroundColour": "#ffffff",
  "showStopButton": true,
  "dwellTimeMs": 1200,
  "switchScanning": false,
  "scanSpeedMs": 1400,
  "scanPattern": "linear"
}
```

Access-specific guidance:

- Eye gaze/dwell: `dwellTimeMs` 1000–1500, target floor 120+ px.
- Switch: set `switchScanning: true`; start with `scanPattern: "linear"`; use `row-column` for larger grids.
- Print-only: still include `showLabels`, attribution, and large labels.

## Accessibility

```json
{
  "intendedAccess": ["touch", "mouse", "keyboard", "eye-gaze-dwell", "switch-scanning"],
  "minimumTargetSizePx": 120,
  "dwellSafe": true,
  "scanOrder": "dom-order",
  "audioCues": true
}
```

Keep `scanOrder` aligned with page/button order. Do not visually rearrange buttons away from DOM order unless the player also updates scanning/focus order.

## Page Object

```json
{
  "id": "page-main",
  "name": "Main",
  "layout": "grid",
  "gridColumns": 3,
  "gridRows": 3,
  "margin": 10,
  "backgroundColour": "#ffffff",
  "backgroundImage": null,
  "buttons": []
}
```

Grid position is typically percentage-based in each button:

```json
"position": { "x": 0, "y": 0, "width": 33.3333, "height": 33.3333 }
```

For generated boards, compute positions left-to-right, top-to-bottom.

## Button Object

Recommended shape:

```json
{
  "id": "btn-help",
  "type": "standard",
  "label": "Help",
  "symbolId": null,
  "symbolSrc": "",
  "searchTerm": "help",
  "symbolLayout": "label-bottom",
  "symbolateSegments": [],
  "position": { "x": 0, "y": 0, "width": 33.3333, "height": 33.3333 },
  "style": {
    "borderColour": "#17212b",
    "borderWidth": 3,
    "borderStyle": "solid",
    "shape": "rounded-rect",
    "fillColour": "#ffffff",
    "gradientColour": null,
    "gradientType": "none"
  },
  "font": {
    "family": "Verdana",
    "size": 18,
    "bold": true,
    "italic": false,
    "colour": "#000000",
    "align": "centre"
  },
  "state": "selectable",
  "audioCue": "Help",
  "result": "selected",
  "actions": [
    { "id": "act-help-speak", "type": "speak-label" },
    { "id": "act-help-log", "type": "log-attempt" }
  ]
}
```

Notes:

- `searchTerm` is useful for AI/symbol workflows even if some older code ignores it.
- `symbolId` should be an ARASAAC pictogram ID when known.
- `symbolSrc` can be a data URL, local/teacher-owned image, or ARASAAC URL.
- `symbolateSegments` supports word+symbol rendering for phrase buttons.
- `type: "symbolate"` or `symbolLayout: "symbolate"` should be used sparingly for short phrases, not paragraphs.

## Actions

Common action types supported by the prototype family:

- `speak-label`
- `speak-text`
- `log-attempt`
- `next-page`
- `previous-page`
- `navigate-page`
- `mark-correct`
- `mark-incorrect`
- `set-variable`
- `increment-variable`
- `conditional`
- `play-audio`
- `open-url`
- `add-to-message`, `speak-message`, `remove-last-word`, `clear-message` — message-bar accumulator for sentence-builder boards (player support added in 0.4.1; the renderer passes them through and the OBF export maps them to `:speak`/`:backspace`/`:clear`)

Keep actions simple in student boards. Overly clever conditional logic is harder to QA with eye gaze/switch users.

## Renderer Output Fields (0.4.x)

`render_open_aac_studio.py` emits everything above plus fields this doc previously omitted:

- Top level: `teacherNotes`, `communicationFunctions`.
- Page: `pattern` (the board pattern name from the IR).
- Button: `role`, `function`, `spokenText`, and optional passthroughs `evidenceTag`, `udl`, `differentiation`, `communicationPartnerCue`. Per-button `style`/`font` from the IR are preserved, merged over the renderer defaults.
- Metadata: `generatedFrom` ("agentic-aac-board-ir"), `sourceIrSchemaVersion`, `accessProfile`, `communicationFunctions`, and an `ir` block preserving SETT/UDL/differentiation/participation-barrier/evidence-plan/symbol-strategy design metadata.
- Actions: when a button declares no actions the renderer's fallback emits `speak-text` (with the resolved spoken text) plus `log-attempt`, not `speak-label`. `navigate-page` actions carry BOTH `targetPageId` and `pageId` so the documented IR contract and the player agree.

## Metadata And Privacy

Use:

```json
"metadata": {
  "tags": ["aac", "choice-board"],
  "level": "",
  "curriculum": "",
  "privacyLevel": "anonymous"
}
```

Avoid student names and diagnoses. If a teacher needs student-specific vocabulary, use labels like `student choice`, `favourite activity`, or locally edited placeholders unless they explicitly provide safe local content.

## Licences

When using ARASAAC:

```json
{
  "source": "ARASAAC",
  "licence": "CC BY-NC-SA",
  "attribution": "Pictograms by ARASAAC (Government of Aragon)"
}
```

If teacher-owned custom photos are used, note `source: "Teacher-owned local image"` and avoid uploading private images to AI services unless explicitly approved.
