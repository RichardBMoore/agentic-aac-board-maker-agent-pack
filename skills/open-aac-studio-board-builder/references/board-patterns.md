# Board Patterns And Vocabulary Recipes

Use these patterns when creating fast Open AAC Studio boards.

## Universal Vocabulary To Consider

Almost every board benefits from at least one repair/agency option:

- Help
- Stop
- Finished
- More
- Different
- Again
- I don't know
- Show me
- Wait
- Break
- My turn
- Not that

Do not add all of these automatically to tiny boards. Choose the ones that fit the purpose.

## 2–4 Button Yes/No Board

Use for quick preference, consent, comprehension, partner-assisted choices.

Default 2x2 labels:

1. Yes
2. No
3. Help
4. Finished

Access notes: very large targets; good for early eye-gaze trials.

## 6–9 Button Choice Board

Use for preferences, classroom participation, topic vocabulary, HPE/English/Science responses.

Typical 3x3 structure:

- Row 1: core/agency options.
- Row 2: task-specific choices.
- Row 3: comment/repair/finish options.

Example positions:

1. I want
2. More
3. Finished
4. <topic 1>
5. <topic 2>
6. <topic 3>
7. Help
8. Different
9. Stop

## First-Then Board

Use for routines, transition, task framing, or sequencing. Avoid using it only as compliance.

Labels:

- First <task>
- Then <preferred/next activity>
- Help / Wait if using 2x2
- Finished / Change if using 2x2

Access: 2 huge cells is better than 8 tiny cells.

## Visual Schedule

Use for routines and multi-step tasks.

Guidelines:

- 3–8 steps for gaze/switch unless tested.
- Use chronological order left-to-right/top-to-bottom.
- Include Done/Finished and Help.
- Keep navigation stable if multi-page.

## Quiz / Comprehension Board

Use carefully. It should not be the only way a student communicates.

Default 2x2:

- Correct target
- plausible distractor
- plausible distractor
- Help / I don't know

For assessment, log `correct`/`incorrect`, but keep feedback calm and non-punitive.

## Opinion + Reason Board

Use for English, HASS, HPE, social/emotional, book responses, hero speeches.

Example 3x3:

1. I think
2. I like
3. I don't like
4. because
5. important
6. interesting
7. Help
8. Different
9. Finished

Add a second page for content-specific nouns/facts if needed.

## Sentence Builder

Use for scripts, speeches, written responses, or oral rehearsal.

Pages:

1. Starters: I think, I feel, I want to say, My idea is.
2. Reasons: because, so, first, next, also.
3. Topic words: lesson-specific vocabulary.
4. Control/repair: speak, clear, back, help, finished.

Keep the student output visible/speakable if implemented in app code.

## Needs / Support / Communication Repair Board

Use as a dignity and access tool, not behaviour control.

Potential vocabulary:

- Help
- Stop
- Break
- Toilet
- Drink
- Pain
- Too loud
- Too hard
- I need more time
- I don't understand
- Different
- Finished

## QCIA Goal Board

Translate goal into practical communication moves.

Examples:

- Community access: go, stop, help, safe, money, bus, shop, where, finished.
- Personal/living: wash, cook, clean, first, next, hot, sharp, help, done.
- Leisure: choose, like, don't like, again, my turn, music, game, outside.
- Transition: work, break, next, finished, help, job, home, plan.

## Australian Curriculum Board

Do not simply list curriculum nouns. Convert into participation moves:

- English: character, setting, problem, I think, because, evidence, retell, question.
- Mathematics: count, more, less, same, different, add, take away, pattern, how many.
- Science: observe, predict, change, living, non-living, test, record, why.
- HASS: place, past, now, community, map, rule, people, important.
- HPE: safe, healthy, feelings, team, move, help, choice, respect.
- Technologies: plan, make, test, improve, safe, digital, problem, solution.
- Arts: look, make, perform, listen, music, colour, movement, share.

## Board Size Defaults

- First trial / high support: 2x2.
- General choice board: 3x3.
- Confident direct touch/mouse: 4x4 possible.
- Eye gaze: 2x2 or 3x3 preferred; 4x4 only after testing.
- Switch scanning: 2x2 or 3x3 first; row-column for larger boards.
