Agentic AAC resource generation

A governed workflow where de-identified teacher intent becomes a validated AAC Board IR, then draft classroom supports: HTML, print, or Open AAC Studio JSON.

Why this exists

Good AAC resources depend on hidden professional knowledge.

The classroom need

Teachers need quick, adaptable resources for lessons, routines, assessments, community access, QCIA evidence, and participation.

The risk

AI can easily produce a pretty picture grid that only lets a student comply, answer, or be tested. Visual support is useful, but it is not automatically expressive AAC.

The goal is not just a chatbot making picture grids. The goal is an educator-governed agent workflow that drafts board-maker-ready resources from structured AAC rules.
Worked example: one board through the workflow

Teacher intent: “Make an eye-gaze choice board for choosing a class activity.”

What the student needs to do

Choose a class activity, ask for help, or say the offered choices are not right.

Access assumption: eye-gaze/dwell, with mouse, touch and keyboard fallback for testing and classroom flexibility.

This is intentionally simple: the value is not the six buttons; it is the repeatable pathway that preserves access, agency and validation. It remains a draft support until tested with the student, device and team.

What the student can do

The example is small, but it is not only a choice grid.

1
ChooseSelect from real activity options using eye gaze, mouse, touch or keyboard.
2
RepairUse Help or Different when the offered options, timing or access are not working.
3
Refuse or negotiateDifferent gives a pathway out of adult-offered choices rather than trapping the student in compliance.
4
Be modelled toTeacher notes prompt adults to model language, wait, and accept multimodal responses.

This is the core design claim: AI should draft supports that preserve student voice and agency, not just generate attractive symbols.

Engineering model

The AAC Board IR is the source of truth.

Agents draft. Humans approve use. Educator and team judgement sits above every step.

Visual process

One canonical IR feeds the classroom outputs.

The board is not reinvented separately in HTML and Open AAC Studio. The outputs are renderer products from the same inspected source.

Inspectable transform

Canonical AAC Board IR

The source-of-truth JSON keeps AAC purpose, access, symbols and QA rules visible before anything is rendered.

{
  "format": "agentic-aac-board-ir",
  "access": { "profile": "eye-gaze-dwell" },
  "communicationFunctions": ["choose", "repair", "refuse"]
}
What makes this engineered, not just prompted

The board is represented before it is drawn.

The IR forces the agent to state the student’s purpose, access profile, communication functions, button roles, symbol strategy, privacy level and teacher notes.

This prevents “pretty HTML with weak AAC logic”. Rendered outputs must preserve the IR.

{ "schemaVersion": "0.2.0", "format": "agentic-aac-board-ir", "title": "Choose a Class Activity", "access": { "profile": "eye-gaze-dwell" }, "communicationFunctions": [ "choose", "repair", "refuse" ], "pages": [{ "grid": { "rows": 2, "columns": 3 }, "buttons": [{ "id": "btn-help", "label": "Help", "role": "repair", "function": "repair", "spokenText": "Help please" }] }] }

How the tools fit together

Each agent has a bounded job.

Claude
Educational structure

Reviews communication purpose, curriculum participation, risks and vocabulary. Produces a board plan.

OpenAI
Structured transform

Turns the plan into canonical AAC Board IR and checks explicit functions and access assumptions.

Codex
Implementation QA

Checks HTML, JavaScript, dwell behaviour, keyboard support, renderers and bugs.

Hermes
Skill-pack validation

Loads the skill pack, validates IR, renders outputs and keeps AAC rules visible.

Gemini
Visual polish

Can refine layout and presentation after the communication structure is locked.

The human team remains accountable: agents draft; educators and relevant allied health approve use.

Veracity check

  • All six proof-of-concept prototype packages created locally.
  • Each package includes README, offline HTML, canonical IR JSON and Open AAC Studio JSON.
  • All generated IR files pass static IR validation.

What leadership can ask for

Useful governance and privacy questions for school leadership.

Quality questions

  • Does the resource preserve student voice and agency?
  • Does it match the access method?
  • Does it preserve the curriculum/evidence intent?
  • Can the IR, output and validation trail be inspected?

Risk questions

  • Has sensitive student information been minimised?
  • Are images/symbols licensed or teacher-owned?
  • Is it a draft support, not clinical prescription?
  • Has it been tested with the actual student/team?
Honest implementation limits

This is not yet a zero-friction school workflow.

1
EQ environmentNot currently available in the standard Education Queensland school environment without an approved setup.
2
Cost sits with the creatorToken/API cost is currently absorbed by the classroom teacher or person creating the files unless a school-funded arrangement is made.
3
Technical setupThe workflow requires enough technical confidence to upload or install SKILL.md files, enable plugins, manage local folders and run checks.
4
Governance gapA practical pilot would need a clear approved environment, cost model, privacy process, and support pathway before broad teacher use.
Suggested pilot request

Ask for a small approved pilot, not broad deployment.

1
ScopeUse de-identified teacher requests only and limit the first run to the six fixture-style resources.
2
ReviewTeaching team and relevant allied health review outputs before any student reliance.
3
StorageNo student data in external tools; store outputs locally or in a school-approved location.
4
EvaluationMeasure usefulness, workload, access fit, technical friction, cost and privacy risks.
Bottom line

This is a fast workflow, but not a shortcut around judgement.

The engineering gives us repeatability: skill files, canonical IR, renderers, scripts and QA. The educational standard remains the same: accessible in practice, curriculum-strong, and preserving student voice.

Honest caveat

This creates draft classroom supports. Resources should be reviewed by the teaching/SLP/OT team and tested with the actual student, access method, device and school environment before relying on them.
