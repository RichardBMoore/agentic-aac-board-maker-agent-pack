# Choose a Class Activity — Eye-Gaze Choice Board

Generated from the first proof-of-concept fixture: `gaze-choice-2x2` / “Make an eye-gaze choice board for choosing a class activity.”

## Files

- `gaze-choice-class-activity.ir.json` — canonical AAC Board IR source of truth.
- `gaze-choice-class-activity.html` — single-file offline HTML player for classroom use.
- `gaze-choice-class-activity.open-aac-studio.json` — renderer output created from the IR.

## Access

- Eye gaze / dwell, mouse, touch, and keyboard.
- 2 x 3 grid, six large targets.
- Dwell default: 1000 ms.
- Pointer leave/blur cancels dwell.
- Tab + Enter/Space works as keyboard fallback.
- Stop Speech control included.

## Communication purpose

The board lets a student choose a class activity and use repair language rather than being trapped in only adult-offered choices. Communication functions realised by the six buttons: choose and repair.

## Teacher note

Replace Read, Art, Game, and Music with the real activity choices. Keep Help and Different stable where practical so the student has a predictable repair pathway.

## Caveat

This is a draft classroom support. Review with the teaching/SLP/OT team and test on the actual eye-gaze device, browser, and student access setup before relying on it.
