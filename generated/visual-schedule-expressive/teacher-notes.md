# Teacher notes - Morning Routine Expressive Visual Schedule

Fixture: `visual-schedule-expressive`

## Purpose

A visual schedule that shows morning routine order while preserving expressive options for waiting, help, change, finished and student comments.

## How it works

- **Morning routine** (3x3): Arrive, Bag away, Morning job, ABC, Group time, Talk about it ▶, Help, What's next?, Finished.
- **Talk about it** (3x3): Wait, Change, I like it, ◀ Morning routine, I don't like it, Core words ▶, Help.

The house standards tool added a **Core words** page (I, want, don't, like, go, more) that builds messages in the message bar and an **ABC keyboard** (QWERTY letter groups, then letters; Speak, Delete and Help on the keyboard page). Talking pages link forward with the right-middle button and back with the left-middle button; ABC sits left-middle on the first page.

## Partner card (summary)

- Model this week: What's next?, Wait, I like it, Finished.
- Wait at least 15 seconds after you model, comment or ask.
- Comment more than you question, for example: Touch What's next? as you check the schedule together.
- If more support is needed, go from least to most help and never move the student's hand (no hand-over-hand).

Print `partner-card.html` for everyone who talks with the student.

## Notes

### Modelling

Point to schedule steps as they happen and model expressive messages, especially Wait, Help please, Change and Finished.

### Customisation

Replace routine steps with the actual class morning sequence and photos if available and approved.

### Schedule order

The first row and early second-row buttons are the routine sequence; the remaining buttons are expressive supports, not compliance controls.

### Not full aac claim

This is a visual schedule with communication supports. It is not a replacement for the student's full AAC system.

## Evidence

Note whether the student anticipates next steps, requests help/wait/change, or comments on readiness.

Prompted routine use is participation/access evidence, not a standalone judgement of independence.
