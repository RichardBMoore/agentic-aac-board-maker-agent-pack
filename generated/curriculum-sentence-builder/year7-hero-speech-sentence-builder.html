Teacher notes

Model: Model a complete sentence chain across both pages: My hero is … brave … because … helps others, then press Speak sentence. Accept partial sentences as valid drafting or rehearsal.

Evidence: sentence built in the message bar; opinion/because/example selection; speak-sentence use; repair (undo, start again) or help request

Customise: Replace the describing words and the hero name with the class text, film, novel or local hero being studied. Add the hero's name as a word button or let the student say it after 'My hero is'.
